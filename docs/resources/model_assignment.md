# `hermes_model_assignment` Resource

Assigns Hermes' main or auxiliary model through the authenticated dashboard REST API.

## Example Usage

```terraform
resource "hermes_model_assignment" "main" {
  model_provider = "custom"
  model          = "my-model"
  base_url       = "http://llm.example.com:8000/v1"
}
```

For an auxiliary task:

```terraform
resource "hermes_model_assignment" "vision" {
  scope          = "auxiliary"
  task           = "vision"
  model_provider = "custom"
  model          = "my-vision-model"
  base_url       = "http://llm.example.com:8000/v1"
}
```

Supported scopes are `main` and `auxiliary`. Auxiliary assignments require a task name. `profile` can target a named Hermes profile.

Destroy removes the Terraform/OpenTofu resource from state without changing Hermes, because there is no reliable previous-model value to restore.

## Schema

### Required

- `model` (String) Model identifier understood by the selected Hermes backend.
- `model_provider` (String) Hermes model backend, such as `custom` or `openai`.

### Optional

- `api_key` (String, Sensitive) Optional provider API key. It is stored in Terraform/OpenTofu state; prefer Hermes secret references when available.
- `base_url` (String) OpenAI-compatible base URL for custom or local providers.
- `confirm_expensive_model` (Boolean) Explicitly confirm Hermes' expensive-model warning when assigning this model. Hermes otherwise returns a plan-time apply error when confirmation is required.
- `profile` (String) Optional Hermes profile to configure.
- `scope` (String) Assignment scope: `main` (default) or `auxiliary`.
- `task` (String) Auxiliary task name when `scope = "auxiliary"`.

### Read-Only

- `id` (String) The ID of this resource.
