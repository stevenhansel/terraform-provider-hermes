# `hermes_skill_installation` Resource

Manages a skill-hub installation through Hermes' security-scanned background
action API.

## Example Usage

```terraform
resource "hermes_skill_installation" "morning_brief" {
  profile    = "default"
  identifier = "official/productivity/morning-brief"
}
```

Create and destroy wait for the bounded Hermes action status endpoint. Action
log lines are never copied into Terraform/OpenTofu state or provider errors.
Use `hermes_skill` separately when activation state must be managed.
