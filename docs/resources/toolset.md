# `hermes_toolset` Resource

Manages the enabled state of one built-in Hermes toolset. Toolsets are toggles,
not independently created remote objects.

## Example Usage

```terraform
resource "hermes_toolset" "web" {
  profile = "default"
  name    = "web"
  enabled = true
}
```

Destroy disables the toolset. Enabling some toolsets can cause Hermes to start
its own post-setup action; this provider does not silently execute or poll that
action.
