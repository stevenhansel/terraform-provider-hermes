# `hermes_skill` Resource

Manages activation state for an existing Hermes skill. It does not create or
edit skill files.

## Example Usage

```terraform
resource "hermes_skill" "morning_brief" {
  profile = "default"
  name    = "morning-brief"
  enabled = true
}
```

Hermes currently omits disabled skills from its inventory endpoint. Create or
import a visible skill before managing a disabled desired state; destroy
disables an existing skill and never deletes its files.
