# `hermes_plugin` Resource

Manages one Hermes agent-plugin installation and runtime activation state.

## Example Usage

```terraform
resource "hermes_plugin" "reviewed" {
  # Replace this placeholder with a curated catalog name or a reviewed
  # owner/repository source before applying.
  identifier = "owner/repository"
  ref        = "0123456789012345678901234567890123456789"
  enabled    = false
}
```

Plugin installation may clone and execute third-party code. Prefer Hermes
catalog entries or reviewed HTTPS/SSH Git sources, pin custom sources to a full
commit SHA, and keep `force = false` unless caution-level scan findings have
been reviewed. Dashboard-only plugins remain outside this resource.

## Schema

### Optional

- `catalog_name` (String) Curated Hermes plugin catalog name. Hermes resolves and pins the catalog source server-side.
- `enabled` (Boolean) Whether Hermes should enable the plugin at runtime. Disabling preserves the installation.
- `force` (Boolean) Whether to accept caution-level Hermes plugin scan findings. Dangerous findings remain blocked upstream; review this security-sensitive option carefully.
- `identifier` (String) Custom Hermes plugin source, such as `owner/repository` or an HTTPS/SSH Git URL. Do not use local `file://` sources.
- `ref` (String) Optional full 40-character commit SHA for a custom source. Tags and branch names are intentionally not accepted.
