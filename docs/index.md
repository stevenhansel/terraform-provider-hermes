# Hermes provider

The Hermes provider manages durable Hermes dashboard configuration through its authenticated management API.

## Example usage

```terraform
terraform {
  required_providers {
    hermes = {
      source  = "stevenhansel/hermes"
      version = "~> 0.1"
    }
  }
}

provider "hermes" {
  endpoint = "https://hermes.example.com"
}
```

The provider accepts `HERMES_DASHBOARD_URL`, `HERMES_DASHBOARD_USERNAME`, and `HERMES_DASHBOARD_PASSWORD` environment variables. Prefer environment variables or an external secret manager for machine credentials.
